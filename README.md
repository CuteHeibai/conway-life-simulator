# Conway Life Simulator

一个基于 Tkinter 的康威生命游戏桌面模拟器。

功能：

- 启动时显示康威生命游戏规则
- 左键拖动画布
- 右键点击或拖动填充/擦除细胞
- 开始、暂停、单步、清空和随机生成
- 随机生成可自定义细胞数量和离散程度，并围绕当前视图中心生成
- 调整倍速，每一代都会显示，不跳代
- 鼠标滚轮缩放画布
- 右键拖动画布
- 保存和载入 `.life` 初始图案
- 检测到循环状态后可选择提示并暂停，或继续运行
- 小缩放下合并绘制连续细胞，减少卡顿
- 细胞过多时自动采样显示，计算仍保留完整细胞
- 统计窗口显示活细胞数量变化趋势
- 可识别原地循环和平移循环

运行源码：

```bat
python conway_life.py
```

打包后的软件位于 `dist\ConwayLifeSimulator.exe`。
